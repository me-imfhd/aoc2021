part2:

rule: if finding oxygen then mcb wins and if equal bits then 1 wins
if finding CO2 then lcb wins and if equal bits then 0 wins

we need to skip ids based on this rules
that is
if finding O2 then find the low_state and high state as we are already doing
and if low_state > high_state we choose low state and skip all the id's which
contributed for high_state
for e.g,

id, char, pos

2, 1, 1
3, 1, 1
1, 0, 2

3, 0, 2
1, 1, 3

3, 1, 3

solving for O2:
in first position partition we get more high states than low states,
that is id 2, 3 should be preserved and id 1 should be skipped
basically in second position partition we only check for id 2 and 3
when checking for second position id 2 3 we get equal high_states and low_states
so we preserve high_states and id's with low state that is 3 should be skipped
now we have only one id preserved that is id 2, so
1,1,0 is our answer for O2

solving for CO2:
in first position partition we get more high states than low states,
that is id 1 should be preserved and id 2,3 should be skipped
now we have only one id preserved that is id 1, so
0,1,1 is our answer for CO2
